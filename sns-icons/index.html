SNS のアイコンとプロフィール案

2026-11-05 ・ Instagram／TikTok／X／note を1つにそろえる案

先に、正直な意見

「40代のおじさん」が悪いのではなく、アイコンが いまの中身を何も伝えていないのが問題だと思います。オレンジの背景にスーツの男性は、5月の「AI で副業」のころに作ったもので、ビジネス系の副業アカウントでよく見る形です。いまの中身は「子どもと遊べるゲームとアプリ」なので、見た人の頭の中で つながりません。

Instagram と TikTok は、動画を見て「このゲームの人だ」と思い出してもらう場所です。アイコンは 小さな丸（いちばん小さいと 32px）でしか見られないので、効くのは「目と口がある顔＋1色の背景」です。人の写真や細かい絵は、その大きさでは読めません。

一方で「会社員で3児のパパが、夜にこつこつ作っている」は、X と note では いちばん強い話です。だから人の顔はやめて、話はプロフィール文に残すのがよいと考えます。4つの SNS で同じアイコン・同じ名前にすると、動画 → LP → X・note と渡り歩いた人が「同じ人だ」と気づけます。

おすすめは A（キャラクター「セラ」）。顔があって、頭のブロックで「作っている人」も伝わり、どの作品にも寄りすぎません。

アイコン 4案

押すと、下のプロフィールの見本が その案に変わります。下の小さい丸は 48px と 32px（タイムラインでの大きさ）。

プロフィールの見本（Instagram）

ケセラセラ｜パパが作るゲームとアプリ
@queserasera012
queserasera012.github.io

プロフィール文（コピーして使えます）

・アプリの本数は いま公開中の5本で書いています。Diner Street が公開されたら「5本」を「6本」に直してください。
・アルクエストと Diner Street は「子ども向け」と名乗らない約束なので、「親子で遊べる知育アプリ＋大人も遊べるゲーム」と分けて書いています。
・ユーザー名（@queserasera012 など）は変えなくてよいです。変えるのは 表示名・アイコン・文だけ。

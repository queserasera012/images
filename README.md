# images

note 記事や X 投稿で使う画像の**公開置き場**です。

note のインポート機能は、**公開URLの画像なら本文に取り込んでくれます**。
画像をここに置いておくと、インポート後に画像を1枚ずつ貼る作業がなくなります。

制作物の原本は private リポジトリ (`claude-company`) にあります。
ここに置くのは、**公開記事で実際に使う画像だけ**です。

## URL の作り方

```
https://queserasera012.github.io/images/<パス>
```

例:

```
https://queserasera012.github.io/images/note/17-shinme-part3/01_kk-yozora-blocks.png
```

## フォルダの切り方

```
note/<弾番号>-<スラッグ>/    … note 記事ごと
x/<キャンペーン名>/          … X のカード画像（今後）
```

記事ごとにフォルダを切ります。ファイル名の `01_` `02_` は本文に出てくる順番です。

## 中身

| パス | 記事 |
|---|---|
| `note/16-shinme-part2/` | しんめ工房、できるまで②発見編（第16弾・公開済み） |
| `note/17-shinme-part3/` | しんめ工房、できるまで③共作・発信編（第17弾） |
| `note/18-web3-to-shinme/` | 続かなかったのは、意志が弱いからではなかった（第18弾） |

## 注意

- **ここに置いた時点で、誰でも見られます。** 公開記事に載せる画像だけを置くこと
- アプリのスクリーンショットは**撮影用のプロフィール**（たろう／はなこ）で撮ったものです。
  実在の子どもの情報は含みません
- 画像を差し替えるときは、**URLを変えない**（記事側の参照が切れます）。
  差し替えではなく追加にするか、記事側も直すこと

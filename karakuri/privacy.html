このアプリは、利用者の情報を一切 収集しません。

This app does not collect any user data. It has no network features, no advertising, and no analytics.

1. 収集する情報

ありません。 このアプリは、名前・メールアドレス・年齢・位置情報・端末の識別子など、 利用者に関するいかなる情報も収集しません。

個人を特定できる情報収集しません
利用状況・解析データ収集しません（解析ツールを組み込んでいません）
広告識別子（IDFA など）収集しません（広告を表示しません）
連絡先・写真・位置情報・マイク・カメラアクセスしません
クラッシュログ収集しません

2. 端末の中に保存されるもの

遊んだ記録を、お使いの端末の中だけに保存します。 これらが端末の外へ送られることはありません。

  • クリアした面
  • 面ごとの自己ベスト（使った手数）
  • 遊び方の設定

アプリを削除すると、この記録も一緒に消えます。 （削除した記録を元に戻す方法はありません）

3. 第三者への提供・外部との通信

  • 通信しません。 インターネットに接続していなくても、すべての機能が使えます
  • 第三者に情報を渡しません。 渡す情報がそもそもありません
  • 広告を表示しません。 広告ネットワークを組み込んでいません
  • アプリ内課金・サブスクリプションはありません
  • 外部サービスの SDK を組み込んでいません

4. お子さまのプライバシーについて

このアプリは子ども向けに作られています。 情報を一切 収集しないため、保護者の同意を必要とする情報の取り扱いは発生しません。

アカウント登録・ログイン・チャット・他の利用者との通信機能は、いずれもありません。 外部サイトへのリンクもありません。

5. ポリシーの変更

内容を変更する場合は、このページを更新し、上部の「最終更新」の日付を改めます。 情報を収集する仕組みを追加する場合は、追加する前にこのページで明示します。

English Summary

This app collects no data whatsoever. It has no network capability, no advertising, no analytics, no third-party SDKs, no accounts, no chat, and no in-app purchases.

Game progress (cleared stages, best move counts, and settings) is stored only on the user's device and is never transmitted anywhere. Deleting the app deletes this data permanently.

Because no information is collected, no parental consent mechanism for data handling is required. For support, please contact @queserasera_012 on X.

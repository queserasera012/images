見た目の出し直し：動きをコードで作る3案

1枚絵をコマ送りする作り方をやめ、体をパーツに分けて関節で動かす（または、ドットを並べ替える）作り方にした。キャラも敵も背景もすべてコードで描いているので、動きを足すときも、仲間を増やすときも、絵にお金はかからない。歩数・ストリーク・救済の印など、中身は基本構想のまま。

A　影絵の旅

夕暮れの空に、切り絵の影で旅人が歩く。顔を描かないので子どもっぽくならず、空の色で地味にもならない。光るのは仲間のマフラーと、ストリークの灯りだけ。

動きの作り方：
頭・胴・腕・脚を別の形にして、関節を軸に回す（SVG の部品をアニメで回転）。マントとマフラーはゆらす。
絵を足すときの費用：
0円。新しい仲間や敵は、形（輪郭）を1つ描き足すだけ。色を塗らないので、描く手間も一番少ない。
向かないこと：
表情が出せない。誰が誰かは、帽子・マント・持ち物の形で見分ける。

B　大人のドット

昔のRPGの「ドット絵」を、落ち着いた色でやり直す。キャラは16×24の点で、文字は本文を普通の書体にして読みやすくする。懐かしさで30〜50代に刺さる。

動きの作り方：
点の並び（文字の表）から絵を作り、脚の点だけを入れ替えて4コマで歩かせる。攻撃は腕と剣のコマを差し替える。
絵を足すときの費用：
0円。16×24の表を1つ書けば1体増える。色は8色の中から選ぶので、そろえるのも簡単。
向かないこと：
細かい表情や服の質感は出ない。点が大きいので、画面の中のキャラは小さめになる。

C　インクの線画

羊皮紙の旅路を引きつぐ案。キャラは線で描いた人形で、関節で動く。オーナーが気に入った「歩いた分だけ道が伸びる」「封蝋」はそのまま残る。

動きの作り方：
A と同じ骨組み（関節で回す）を、塗りつぶしではなく線と薄い色で描く。道はインクの線として伸びる。
絵を足すときの費用：
0円。服の形と色を変えた人形を1つ描き足す。
向かないこと：
線が少ないぶん、A-1 の水彩の絵ほどの描き込みは出ない。「手描きの日記の落書き」の手ざわりになる。

B 大人のドット：形で愛着を出す版

かわいさを目ではなく体の形で出す版。頭・帽子・靴を大きく、手足を短くして、遠くから見ても誰か分かる丸いシルエットにした。顔は点の目だけで、魔法使いは帽子の影の中で目だけが光る。点の細かさ（1点 3px）と色の段は前の版のまま。絵はすべてコードで組んでいるので、描き足しても費用はかからない。

画面

どこを細かくしたか

  • 点の大きさ：1点 5px → 3px（画面の上で）。キャラは 16×19点 → 約30×36点
  • 形：2頭身ちょっと。主人公は大きな頭とはねた毛、長いえり巻き、大きな靴。魔法使いは先の折れた大きな帽子と、すそが広がった上着
  • 顔：目は点だけにして、表情は体の動きで見せる。魔法使いは顔が影になっていて、魔法を使うときだけ目が明るくなる
  • 動き：歩くと足を踏み出すたびに体が1点沈み、えり巻きと帽子の先が揺れる。足は常に地面に着いている。斬るは「振りかぶる→振り抜く」、魔法は杖を掲げて水の玉を飛ばす

描き足すときの費用
0円。体は丸・多角形の組み合わせで書いてあるので、帽子や髪型を差し替えるだけで仲間を増やせる。

顔で感情を出しにくい。喜ぶ・落ちこむは、跳ねる・うなだれるなど体の動きで出す。

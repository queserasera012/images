B 大人のドット：細かく描き直した版

前の B より点を小さくして、1体に使う点の数を約3倍にした。色は1つの素材につき明・中・暗の3段を使い、輪郭は真っ黒ではなく焦げ茶にしている。背景の山・雲・木もすべて点で描き、奥のものほどゆっくり流れる。絵はすべて文字の表から作っているので、描き足しても費用はかからない。

画面

どこを細かくしたか

  • 点の大きさ：1点 5px → 3px（画面の上で）。キャラは 16×19点 → 24×36点
  • 頭身：2頭身半 → 3頭身半。30〜50代向けに、子どもっぽさを下げた
  • 色の段：髪・服・肌・剣それぞれに影と光の色を足した。主人公にマント、魔法使いに水晶の杖
  • 動き：歩きは脚3コマ＋マントの揺れ。斬るは「振りかぶる→振り抜く」の2コマと斬撃の光。魔法は水晶が光って水の玉が飛ぶ

描き足すときの費用
0円。仲間1人は 24×36 の文字の表を1枚（頭・胴・脚を分けて書くので、服の色違いは表を書き直さずに作れる）。
向かないこと
表情の細かい変化（泣き笑いなど）は2〜3点でしか描けない。顔はこの大きさが上限で、これ以上細かくすると「ドット絵」より「縮んだイラスト」に見え始める。
このあと
この絵柄でよければ、仲間をあと2人（弓・僧侶）と敵2体を足して、フェーズ0の画面（歩数でレベルが上がる）に載せる。
